# CSC584 - Enterprise Programming

## Group Assignment: Campus Event Discovery and Registration System

This repository contains the source code for our CSC584 Enterprise Programming group project.

The project aims to develop a web-based application that allows UiTM students to discover and register for campus events. Event organizers can create and manage events, while system administrators oversee the system and manage user access.

**Note:** All events are free. No payment functionality is included.

## User Roles

The system consists of three main actors:

### 1. Student

- Register and log in
- Discover, search, and filter events
- View event details
- Save events as interested
- Register for events
- View registration status and event history
- View waitlist status

### 2. Event Organizer

- Log in
- Create new events
- Update and cancel events
- Set participant capacity and registration deadlines
- View participant lists
- Manage event attendance
- View organized events

### 3. System Admin

- Log in
- Monitor overall system activities
- Manage user accounts
- Grant or revoke event organizer access
- Monitor published events

## GitHub Collaboration

Each member will develop their assigned HTML pages in a separate branch.

- `main` - Main project branch
- `student-interface` - Student pages
- `organizer-interface` - Event Organizer pages
- `admin-interface` - System Admin and shared pages

Members should commit and push their changes to their respective branches and create pull requests before merging into `main`.
